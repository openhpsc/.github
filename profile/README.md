# OpenHPSC

**Open High-Performance Spaceflight Computing**

An open foundation for high-performance, dependable computing in space. We bring together open hardware, real-time software, and reproducible verification to advance research and collaboration across the global space community.

Our long-term goal is an ITAR-free reference platform, subject to export-control assessment as the design matures.
